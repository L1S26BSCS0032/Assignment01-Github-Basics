# Sum of first 50 natural numbers 

## Program Description
This C++ program calculates the sum of first 50 natural numbers using two methods.

### Method 1: Using For Loop
The program uses for loop to add numbers from 1 to 50.

### Method 2: Using Mathematical Formula
The program uses the formula:
S = n(n + 1) / 2
where n = 50.

## Sample Output

Sum of the first 50 natural numbers is : 1275

Sum using formula n(n+!)/2: 1275
